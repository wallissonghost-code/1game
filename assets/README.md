# Assets do 1Game

Estrutura visual do jogo. Coloque arquivos novos nas pastas corretas e registre o asset em `config/assets.json`.

- `castles/` — castelos e variações por time/skin
- `mobs/` — guerreiros, arqueiros, magos, bosses e animações
- `maps/` — fundos, chão, obstáculos e elementos do mapa
- `effects/` — explosões, magia, impactos, partículas e eventos
- `ui/` — HUD, ícones, molduras e elementos de interface

Preferência inicial: PNG/WebP com fundo transparente para personagens/castelos/efeitos e WebP/JPG para mapas de fundo.
